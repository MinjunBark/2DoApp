1) Overview
-----------
Developed a full-stack to-do list application using Django for backend API development and React for the frontend user interface.
* Implemented RESTful API architecture to enable seamless communication between Django backend and React frontend.
* Deployed the application using Choreo for virtual hosting and cloud infrastructure management.
* Built CRUD functionality for task management with Django REST Framework and integrated with React components for dynamic user interactions.

2) Features
-----------
- Create, read, update, and delete tasks (CRUD) via a REST API
- Admin interface to manage tasks and users
- Basic task fields: title, description, completed status, created/updated timestamps
- Uses Django ORM for storage (SQLite by default in development)
- Structured to easily add authentication and per-user task lists
